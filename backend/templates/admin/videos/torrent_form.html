Streaming via BitTorrent (WebTorrent)

Cole um magnet link (magnet:?xt=urn:btih:...) ou a URL direta de um arquivo .torrent.
O streaming começa enquanto o arquivo ainda é baixado (download progressivo).

Como funciona o streaming torrent:

  1. O torrent-node (WebTorrent) recebe o magnet e começa a baixar os peers
  2. O arquivo de vídeo maior é selecionado automaticamente
  3. O Flask faz proxy com suporte a Range requests (seek funciona)
  4. O player HTML5 nativo reproduz diretamente no navegador
  5. O download fica em cache enquanto o serviço estiver rodando
